## IMPLEMENTATION NOTES

### For xcstrings format:
```json
"English string" : {
  "localizations" : {
    "es" : {
      "stringUnit" : {
        "state" : "translated",
        "value" : "Spanish translation"
      }
    }
  }
}
```

### Tone Guidelines for Spanish:
- Use "tú" (informal) not "usted" (formal)
- Keep the mystical, direct tone
- Don't over-translate idioms—sometimes English stays
- Spiritual terms often keep their original form
- Match the fire 🔥 energy

### Cultural Notes:
- Latin America has strong esoteric/spiritual communities
- Catholic background means church terminology resonates differently
- Sun worship connects to indigenous traditions (Inti, etc.)
- "Despertar" is widely understood in spiritual contexts
