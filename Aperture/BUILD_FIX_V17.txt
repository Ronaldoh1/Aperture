===============================================

If you're seeing "Multiple commands produce" errors, your Xcode project
has stale file references from previous versions. Follow these steps:

=== QUICK FIX ===

1. In Xcode: Product → Clean Build Folder (Cmd+Shift+K)

2. Delete Derived Data:
   - Close Xcode
   - Run: rm -rf ~/Library/Developer/Xcode/DerivedData/Aperture*
   - Reopen Xcode

3. In Xcode's Project Navigator, look for RED files (missing references):
   - Delete ALL red file references
   - Specifically remove any references to:
     * fastlane/ folder
     * description.txt
     * keywords.txt  
     * release_notes.txt
     * Any MirrorPrincipleView.swift in Alexandria folder
     * Any WealthConsciousnessView.swift in Alexandria folder

4. Re-add source files if needed:
   - Right-click Aperture folder → "Add Files to Aperture"
   - Select the Modules folder
   - Make sure "Copy items if needed" is UNCHECKED
   - Make sure "Create groups" is selected
