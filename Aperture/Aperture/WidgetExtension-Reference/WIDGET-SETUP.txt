# Widget Extension Reference Files

These files are for REFERENCE ONLY - they won't compile with the main app.
The .swift.reference extension prevents Xcode from trying to compile them.

## To Use Widgets

1. **Create Widget Extension Target:**
   - File → New → Target → Widget Extension
   - Name it "ApertureWidget"
   - Choose "Include Configuration Intent" if you want configurable widgets

2. **Copy the code:**
   - Rename `ApertureWidgets.swift.reference` to `ApertureWidgets.swift`
   - Copy it into your new Widget Extension target

3. **Enable App Groups:**
   - Main app target: Signing & Capabilities → + App Groups
   - Widget target: Signing & Capabilities → + App Groups
   - Both must use: `group.com.sunflow.aperture`

4. **Build and test**

## Why Separate Target?

Widget Extensions need their own target because:
- They have their own `@main` entry point
- They use WidgetKit APIs in a different context
- They run as separate processes on the device
