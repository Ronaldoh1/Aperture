## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Installation

1. Clone the repository
2. Open `Aperture.xcworkspace` in Xcode
3. Build and run on simulator or device

## Architecture

- **MVVM** with SwiftUI
- **Combine** for reactive programming
- **UserDefaults** for local persistence
- **CloudKit** for sync (optional)
