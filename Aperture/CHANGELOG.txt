## Upgrade Notes

### 1.4.x → 1.5.x
- Add `NSFaceIDUsageDescription` to Info.plist
- New Core/Auth/ files must be added to project
- Keychain entitlements may be needed

### 1.3.x → 1.4.x
- Firebase Crashlytics requires additional setup
- Run script build phase for dSYM upload

### 1.2.x → 1.3.x
- No breaking changes

### 1.1.x → 1.2.x
- Localizable.strings files added
- Check string keys if customized

### 1.0.x → 1.1.x
- Core Data model updated
- Delete app data on simulator before testing
