## 📱 MVP Features (No Backend Required)

These features work **100% offline** using on-device AI (Apple's NaturalLanguage framework, Core ML) and local storage.

### 1. Hakai Hate - "Check Yourself Before You Post" ✅
**File:** `HakaiHate/HakaiHateView.swift`

- **Post Analysis:** Paste or type your social media post
- **Hate Trigger Detection:** Uses NLP to identify:
  - Divisive language
  - Dehumanizing terms
  - Overgeneralizations ("all X are...")
  - Inflammatory rhetoric
  - Fear-mongering patterns
- **Sentiment Scoring:** 0-100 score with color coding
- **Suggested Rewrites:** AI-powered alternatives
- **Copy to Clipboard:** Easy posting after review

**Tech:** `NLTagger` for sentiment, regex patterns for triggers

## 🔧 Kill Switch / Feature Flag System

**File:** `Core/FeatureFlags/FeatureFlagManager.swift`

### How It Works:

```swift
// Check if feature is enabled
if FeatureFlagManager.shared.isEnabled(.hakaiHate) {
    // Show feature
}

// In SwiftUI
SomeView()
    .featureEnabled(.hakaiHate)
```

### Beta Testing Setup:

1. All MVP features are **ON by default**
2. All V2 features are **OFF by default**
3. Access the dashboard to toggle features:
   - `FeatureFlagDashboardView()`
4. Quick actions:
   - Enable All MVP Features
   - Disable All V2 Features
   - Reset All Overrides

## 🏗️ Architecture

### VIPER-X Pattern

```
AwakeTogether/
├── AwakeTogetherView.swift          # Main hub
├── HakaiHate/
│   └── HakaiHateView.swift          # Post analyzer
├── AwakeningTracker/
│   └── AwakeningTrackerView.swift   # Journey tracker + journal
├── MindShield/
│   └── MindShieldView.swift         # Media diet + grounding
├── EquityWeave/
│   └── EquityWeaveView.swift        # Offer analyzer + wealth sim
└── Interactor/
    └── AwakeTogetherInteractor.swift # Business logic (V2)
```

### Storage Strategy

**MVP (Local):**
- `UserDefaults` for settings and flags
- JSON encoding for complex objects
- `FileManager` for voice notes
- Core Data for larger datasets (optional)

**V2 (Firebase):**
- Firestore for user data
- Firebase Storage for voice notes
- Firebase Auth for accounts
- Remote Config for feature flags

### AI Strategy

**MVP (On-Device):**
- `NaturalLanguage` framework for:
  - Sentiment analysis (`NLTagger`)
  - Text extraction
  - Pattern matching
- `Speech` framework for voice transcription
- Core ML for custom models (future)

**V2 (Cloud):**
- OpenAI API (ChatGPT)
- Anthropic API (Claude)
- xAI API (Grok)
- User preference for AI provider
